## 🎯 Slides Overview
1. **Sustainable Excellence**: Reframing work-life balance from a sign of weakness to an elite performance discipline.
2. **The Anatomy of Burnout**: Hard empirical metrics on the cognitive penalty of chronic fatigue.
3. **From Depletion to Cadence**: The paradigm shift from reactive availability to energy architecture.
4. **The Daily Operating System**: Tactical daily workflow protocol + biological restoration protocol.
5. **The Art of the Strategic 'No'**: Executive communication script for negotiating workload trade-offs.
6. **Managing Career vs Calendar**: Diagnostic reflection on 30-year career pacing.
7. **The Corporate Athlete**: Closing manifesto on sustainable execution.

## ⌨️ Presentation Keyboard Shortcuts
- → / Space : Next slide (steps through pipeline animations on slide 4)
- ← / Shift+Space : Previous slide
- P : Presenter mode (dual-screen sync, speaker notes, rehearsal timer)
- ESC : Thumbnail matrix overview
- B : Low-power / static mode (pauses WebGL fluid background shaders)
- F : Fullscreen toggle
